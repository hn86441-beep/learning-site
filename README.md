# 🛂 جواز سفر اللغوي — Lisan Passport

موقع تفاعلي إبداعي لتعلّم **العربية الفصحى، الإنجليزية، الإسبانية، والروسية**، بفكرة "جواز السفر": كل لغة عالم مستقل بحبر وختم خاص به، تجمع فيه الأختام كلما أتقنت كلمات جديدة.

لا يحتاج المشروع أي إطار عمل (React/Vue...) — HTML و CSS و JavaScript خالص، لذلك رفعه على GitHub وVercel بسيط جدًا ولا يتطلب أي أوامر بناء (build).

## 📁 محتويات المشروع

```
lisan-passport/
├── index.html      الصفحة الرئيسية (الغلاف + صفحات اللغات)
├── style.css        كل التصميم (ثيم جواز السفر)
├── data.js          كل المفردات والجمل — عدّل هنا لإضافة كلمات جديدة
├── app.js           منطق التفاعل: البطاقات، الاختبارات، الأختام، التقدّم
└── README.md         هذا الملف
```

## ✨ الفكرة

- الصفحة الرئيسية "غلاف جواز السفر": تختار منها إحدى اللغات الأربع.
- كل لغة تُفتح كصفحة جواز مستقلة فيها:
  - **كلمة اليوم** تتغيّر تلقائيًا كل يوم.
  - **بطاقات تعليمية** بتأثير القلب (Flip) لحفظ المفردات.
  - **اختبار سريع** متعدد الاختيارات لقياس تقدّمك.
  - **أضف كلمتك** لإضافة مفردات خاصة بك تُحفظ في متصفحك.
  - **أختام الرحلة** تظهر تلقائيًا كلما اجتزت معالم معينة (1، 5، 10...كلمة).
  - **سلسلة أيام** (Streak) تحفّزك على الاستمرار يوميًا.
- التقدم يُحفظ محليًا في متصفحك عبر `localStorage`، فلا حاجة لأي قاعدة بيانات أو خادم.

## 🧩 كيف تضيف كلمات جديدة؟

افتح ملف `data.js` وأضف عنصرًا جديدًا داخل مصفوفة اللغة المطلوبة (`en` أو `es` أو `ru` أو `ar`)، باتّباع نفس الصيغة الموجودة:

```js
{ word: "Example", meaning: "مثال", example: "This is an example.", example_ar: "هذا مثال.", tag: "عام" },
```

## 🚀 الرفع على GitHub

1. أنشئ حسابًا على [github.com](https://github.com) إن لم يكن لديك واحد.
2. أنشئ مستودعًا (Repository) جديدًا، مثلًا باسم `lisan-passport`، واتركه فارغًا (بدون README تلقائي).
3. من جهازك، داخل مجلد المشروع، نفّذ الأوامر التالية في الطرفية (Terminal):

```bash
cd lisan-passport
git init
git add .
git commit -m "أول نسخة من جواز سفر اللغوي"
git branch -M main
git remote add origin https://github.com/USERNAME/lisan-passport.git
git push -u origin main
```

استبدل `USERNAME` باسم حسابك على GitHub.

> بديل أسهل بدون طرفية: من صفحة المستودع على GitHub اضغط **Add file → Upload files**، واسحب الملفات الخمسة مباشرة، ثم اضغط **Commit changes**.

## ☁️ النشر على Vercel

1. ادخل إلى [vercel.com](https://vercel.com) وسجّل دخولك بحساب GitHub نفسه.
2. اضغط **Add New → Project**.
3. اختر مستودع `lisan-passport` من القائمة واضغط **Import**.
4. لأن المشروع HTML/CSS/JS خالص، اترك كل الإعدادات كما هي (لا حاجة لأي Framework Preset أو Build Command) واضغط **Deploy**.
5. خلال أقل من دقيقة سيمنحك Vercel رابطًا مباشرًا مثل:
   `https://lisan-passport.vercel.app`

بعد ذلك، أي تعديل تدفعه (`git push`) إلى GitHub سيُنشر تلقائيًا على نفس الرابط خلال ثوانٍ.

## 🎨 التخصيص

- الألوان والخطوط: أعلى ملف `style.css` داخل `:root { ... }`.
- حبر كل لغة (اللون المميز لها): المتغيرات `--ink-en`, `--ink-es`, `--ink-ru`, `--ink-ar`.
- الخطوط المستخدمة: Cairo للعربية والواجهة، Fraunces للكلمات اللاتينية، Golos Text للسيريلية (الروسية)، Aref Ruqaa للعناوين الفصيحة.

## 💡 أفكار للتطوير لاحقًا

- تصدير/استيراد تقدّمك كملف JSON للنسخ الاحتياطي.
- وضع "تحدي يومي" يجمع كلمات من اللغات الأربع معًا.
